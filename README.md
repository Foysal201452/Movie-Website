# 🎬 Movie Search Website  

A React-based web application that lets users search for movies using an external API.  

## 🔑 Key Features  
- 🔍 Search movies via API  
- ⏳ Debounced search  
- ⚛️ React hooks & reusable components  
- 🎨 Tailwind CSS styling
